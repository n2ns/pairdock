# Security policy

PairDock talks to USB receivers and sends key presses on your behalf, so we take security
reports seriously.

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/n2ns/pairdock/security/advisories/new)
with a description, the affected version and, if possible, steps to reproduce.

We will acknowledge the report within a week and keep you informed until it is fixed.

## Supported versions

Only the latest release receives security fixes.
