## 首次启动

1. 插入 Logi Bolt 接收器。
2. 如果装了 Logi Options+，请从它的托盘图标退出，或者直接卸载。否则两个程序会同时处理同一组按键，快捷键可能触发两次，也可能完全不起作用。
3. 从开始菜单启动 PairDock，打开后显示的是设备列表。

关闭窗口后，PairDock 会继续在系统托盘（时钟旁边的蓝色鼠标图标）中运行，按键快捷键靠它保持生效。

## 设备列表

<img src="images/devices-light.png" width="720" alt="设备列表">

每个接收器会显示已使用的槽位数（共 6 个）和它的唯一编号。下面列出配对在这个接收器上的每个设备：

- **已连接**：设备处于唤醒状态、在接收范围内，同时显示电量。
- **未连接**：设备在休眠、已关机、超出接收范围，或者这是一个设备已不再使用的旧配对（见[旧配对](#旧配对)）。

移动一下鼠标或按一下键盘就能唤醒设备，然后点击**刷新**。

## 配对设备

一个 Logi Bolt 接收器最多可以配对 6 个设备。点击侧边栏的**配对新设备**，或者设备列表里的**配对新设备**卡片。

### 1. 准备

<img src="images/pair-prepare.png" width="720" alt="让设备进入配对模式">

让设备进入配对模式：

- **鼠标**：翻到底部，长按连接按钮约 3 秒，直到指示灯快速闪烁。
- **键盘**：长按一个 Easy-Switch 键（通常是 F1～F3，或者印有电脑图案的键）约 3 秒，直到指示灯快速闪烁。

如果插了不止一个接收器，先选择要配对到哪一个，然后点击**开始搜索**。

### 2. 搜索

处于配对模式的设备会在几秒内出现在列表里，点击它旁边的**配对**。在你选中设备或离开这一页之前，PairDock 会一直搜索。

### 3. 确认

Bolt 设备需要用一串简短的确认码来完成配对，防止附近的人把他们的设备连到你的接收器上。

<img src="images/pair-confirm.png" width="720" alt="用点击确认鼠标配对">

- **鼠标**：按照 10 步的顺序，点击高亮的按键（左键或右键）。鼠标图和下方的一排小图标会显示下一步该点哪个键，进度条记录已点击的次数。点完第 10 下后，**同时按下左右键**，按住约半秒再松开。
- **键盘**：输入屏幕上显示的数字，然后按**回车键**。下一个要输入的数字会被高亮。

多点一下、按错键或等待太久，接收器都会中止配对。让设备重新进入配对模式后，点击**重试**。

### 4. 完成

设备配对成功。如果是鼠标，可以点击**按键设置**直接进入它的按键设置。

#### 旧配对

如果一个设备之前已经配对过同一个接收器，再配对一次时，接收器会保留旧的槽位，而设备只会使用新的那个。PairDock 会根据设备的序列号识别出这种情况，在配对成功页提供**清理旧配对**按钮，清理后可以腾出槽位。

你也可以之后在设备列表里手动删除：同一个设备出现两次，其中一直显示**未连接**的那个就是旧配对。

## 解除配对

点击设备卡片上的**解除配对**并确认。在重新配对之前，这个设备将无法通过该接收器使用。

## 自定义按键

在已连接的鼠标卡片上点击**按键设置**。

<img src="images/buttons.png" width="720" alt="按键设置">

可以在俯视图、侧视图（后退和前进侧键）或右侧列表里选择一个按键。选中的按键会高亮显示，改动过的按键旁边会有一个小圆点。然后选择它的功能：

| 动作 | 效果 |
|---|---|
| **默认** | 按键的出厂功能。 |
| **改成其他按键** | 按键执行另一个按键的功能，例如"后退侧键 → 中键"。设置保存在鼠标上，但鼠标重新连接后会丢失，要靠 PairDock 重新设置，所以需要 PairDock 在托盘中运行。只会列出鼠标允许的目标按键。 |
| **快捷键** | 按住按键时发送一组组合键。可以从常用快捷键中选择，也可以点击**录制**后按下组合键。需要 PairDock 在托盘中运行。 |
| **禁用** | 按键不再有任何作用。需要 PairDock 在托盘中运行。 |

改动会立即生效并自动保存。设置按鼠标型号保存，同型号的另一只鼠标也会使用相同的按键设置。

带 Windows 键的组合（如 `Win+D`）经常在 PairDock 录制之前就被系统处理掉了，这类快捷键请从常用快捷键中选择。

能自定义哪些按键取决于鼠标本身。以 Logi M650 为例：中键、后退和前进侧键、手势键可以自定义，左键和右键不能修改。

## 设置

- **开机自动启动**：登录 Windows 后，PairDock 会在托盘中启动，快捷键马上可用。
- **外观**：跟随 Windows 主题，或者固定使用浅色、深色。
- **语言**：跟随 Windows，或者固定使用中文、English。
- **启动时检查更新**：默认开启。GitHub 上有新版本时，PairDock 会询问是否安装；点击**安装并重启**之前不会下载任何东西。安装时会先把按键恢复为默认功能，然后运行安装程序并重新启动 PairDock，重启后按键设置会重新生效，设置本身会保留。
- **更新 → 检查更新**：立即检查一次。检查时会发送什么，见[隐私说明](../PRIVACY.zh-CN.md)。
- **GitHub 上的源代码**和**在 GitHub 上点 Star**会在浏览器中打开项目页面。

## 托盘与退出

- 点击托盘图标会打开窗口。关闭窗口时，PairDock 会继续在托盘中运行。
- 托盘菜单里的 **Quit** 会退出 PairDock。退出前它会把所有按键恢复为默认功能，这样不运行 PairDock 时鼠标也能正常使用。休眠中的鼠标要等唤醒后才能收到这个设置，所以 PairDock 最多会等待 3 秒。
- Windows 关机时，PairDock 会立即退出。下次接收器通电时，鼠标会以初始状态重新连接。

托盘菜单目前只有英文：**Open PairDock**（打开窗口）和 **Quit**（退出）。

## macOS

在 Mac 上，PairDock 的用法和 Windows 基本相同，区别如下。已在 Intel Mac 的 macOS 15 Sequoia 上测试，尚未测试的部分见[尚未在 macOS 上测试](#尚未在-macos-上测试)。

### 安装与首次启动

1. Apple 芯片的 Mac 下载 `PairDock_x.y.z_aarch64.dmg`，Intel 芯片的 Mac 下载 `PairDock_x.y.z_x64.dmg`。打开后把 **PairDock** 拖进"应用程序"。
2. 打开 PairDock。它暂时没有 Apple Developer ID 签名，也没有经过公证，所以 macOS 会拦下第一次启动。打开**系统设置 → 隐私与安全性**，向下滚动，点击**仍要打开**，再点**打开**确认（[Apple 的说明](https://support.apple.com/zh-cn/102445)）。之后就能正常打开。

### 菜单栏

PairDock 在菜单栏里运行，不出现在程序坞中。点击它的图标（一只带轨道环的鼠标）会弹出菜单：**Open PairDock**（打开窗口）和 **Quit**（退出）。关闭窗口时 PairDock 继续运行；从"应用程序"里再次打开 PairDock 会显示窗口。

### 允许发送快捷键

macOS 只允许拥有**辅助功能**权限的应用发送按键。配对、"改成其他按键"和"禁用"不需要这个权限。

1. 把某个按键设为**快捷键**。缺少权限时，PairDock 会显示提示。
2. 点击**授权…**，在弹出的对话框里点**打开系统设置**。
3. 在**隐私与安全性 → 辅助功能**里打开 **PairDock** 的开关。

提示会在两秒内消失，快捷键立即可用，不需要重启 PairDock。

**每次更新后都要重新授权。** 没有 Developer ID 签名时，macOS 会把每个新版本当成另一个应用，旧的开关即使还显示为打开也不再生效。请在列表里选中 PairDock 点 **−** 删除（或者在"终端"中运行 `tccutil reset Accessibility dev.pairdock.desktop`），再按上面的步骤重新授权。

### 快捷键

常用快捷键使用 Mac 的按键：**浏览器后退 / 前进** `Cmd+[` / `Cmd+]`、**显示桌面** `F11`、**调度中心** `Ctrl+Up`、**左侧空间 / 右侧空间** `Ctrl+Left` / `Ctrl+Right`、**App 的所有窗口** `Ctrl+Down`、**切换 App** `Cmd+Tab`、**关闭窗口** `Cmd+W`、**截图** `Cmd+Shift+4`、**字符检视器** `Ctrl+Cmd+Space`。录制的快捷键显示为 **Cmd** 和 **Option**。

字母和数字按美式键盘上的位置发送，这是 macOS 给按键编号的方式。录制的快捷键使用你实际按下的键，任何布局下都能正常工作。如果使用 AZERTY、Dvorak 等会改变字母位置的布局，在设置文件里写成 `Cmd+W` 的快捷键，按下的是美式键盘上 W 所在位置的那个键。

### 退出

和 Windows 一样，菜单里的 **Quit** 会先把所有按键恢复为默认功能再退出。

### 卸载

先在设置里关闭**开机自动启动**，再退出 PairDock，把它从"应用程序"拖到废纸篓。如果要清除全部痕迹，再删除：

- `~/Library/Application Support/dev.pairdock.desktop`：按键设置（`config.json`）
- `~/Library/WebKit/dev.pairdock.desktop` 和 `~/Library/Caches/dev.pairdock.desktop`：窗口数据（语言和外观）
- `~/Library/LaunchAgents/PairDock.plist`：开机启动项（如果还在）

并在**系统设置 → 隐私与安全性 → 辅助功能**里移除 PairDock。

## 故障排查

**提示"没有找到罗技接收器"**：把接收器插到电脑的 USB 口上，然后点击**刷新**。Unifying 接收器能被识别，但暂时还不能使用。

**提示"设备正在休眠"**：移动一下鼠标或按一下键盘，然后点击**重试**。

**搜索时找不到设备**：确认设备的指示灯在快速闪烁，配对模式过一段时间会自动结束，需要重新长按连接按钮。Bolt 设备只能被 Bolt 接收器发现。

**配对在最后一步失败**：左右键要在完全同一时刻按下。如果其中一个键按早了一点，会被当成多点了一下。

**快捷键不起作用了**：PairDock 必须在运行，看看托盘里有没有它的图标，没有就重新启动。如果 Logi Options+ 也在运行，请退出它。

**快捷键只在某个窗口里不起作用**：Windows 不允许普通程序向以管理员身份运行的窗口（例如任务管理器）发送按键（见 [SendInput](https://learn.microsoft.com/zh-cn/windows/win32/api/winuser/nf-winuser-sendinput)）。切换到其他窗口后，PairDock 的快捷键会恢复正常。

**PairDock 崩溃后某个按键没反应了**：PairDock 没来得及把按键恢复成默认功能。启动 PairDock 后从托盘菜单退出一次，或者把鼠标关机再开机。

**Windows SmartScreen 拦截了安装程序**：安装包暂时没有代码签名。点击**更多信息 → 仍要运行**。

如果以上都没有解决问题，请[提交问题](https://github.com/n2ns/pairdock/issues/new/choose)，写明设备型号。[CONTRIBUTING.md](../CONTRIBUTING.md) 里介绍了如何录制协议日志，方便我们查看接收器的具体应答。

## 卸载

在 Windows 的**设置 → 应用 → 已安装的应用**中卸载 PairDock。设备会继续保持与接收器的配对。

PairDock 的文件保存在下面两个文件夹里，删除它们即可彻底清除：

- `%APPDATA%\dev.pairdock.desktop`：按键设置（`config.json`）
- `%LOCALAPPDATA%\dev.pairdock.desktop`：窗口数据（语言和外观设置）
